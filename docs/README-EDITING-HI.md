# Apna Bihar Samachar LIVE — साइट संपादन गाइड

## वेबसाइट
यह GitHub Pages पर चलने वाली static HTML वेबसाइट है। WordPress/PHP/WooCommerce backend इसमें नहीं चलता।

## Deploy
Repository: https://github.com/onkarnbcohe121-del/apna-bihar-samachar
1. Settings → Pages खोलें।
2. Build and deployment में Deploy from a branch चुनें।
3. Branch: main और folder: /docs चुनकर Save करें।
4. प्रकाशित URL: https://onkarnbcohe121-del.github.io/apna-bihar-samachar/

## बदलाव
- मुख्य पेज: docs/index.html
- डिजाइन: docs/assets/style.css
- खबरों का नमूना अभी HTML में है। नई खबरें प्रकाशित करने से पहले स्रोत, तारीख, आँकड़े और तथ्य जाँचें।
- YouTube चैनल लिंक index.html में है।

## बुक स्टोर की सीमा
यह static site है। Printed book enquiry WhatsApp link से ली जा सकती है। Paid PDF के लिए secure payment verification, private file storage और post-payment download link देने वाला backend/payment provider चाहिए। PDF को public GitHub repository में कभी upload न करें—वह सबके लिए खुली होगी।

## खर्च
GitHub Pages public repository पर GitHub Free में उपलब्ध है। Free plan पर repository public होगी। साइट सार्वजनिक रूप से देखी जा सकती है।
